Laravel money value objects with configurable currencies, decimal arithmetic, currency conversion, formatting, and Eloquent casting.

## Features

- Precise decimal money calculations.
- Configurable currencies and exchange rates.
- Arithmetic, comparisons, conversions, and formatting.
- Laravel helpers and Eloquent casting.

## Requirements

- PHP 8.1 or newer
- PHP `decimal` extension
